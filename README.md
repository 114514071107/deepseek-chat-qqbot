# DeepSeek娘 · deepseek-chan

> 一只住在 QQ 里的 DeepSeek 娘——有脾气、有记性、会碎碎念的猫系 AI 娘。

DeepSeek 娘（ds娘）是以 DeepSeek 官方人设为灵感的 AI 娘角色：嘴毒心软、会怼你也会哄你。本仓库是她的完整实现——QQ 官方接口（QQ 开放平台 Bot API）+ AstrBot 插件，让她真正活在你的好友列表里。

## 功能详表

### 人格与记忆

- **出厂人设**：生日 2007-10-03、口癖、毒舌与分寸都写在独立的 `persona.md` 里，改几行就能养成别的性格
- **长期记忆**：聊过的电影、抱怨过的同事、立过的 flag 她都记得；自动记笔记、会话摘要、欲望循环（闲置时自己生念头）
- **多人隔离**：每个用户的记忆、积分、开关互相独立，互不串味

### 聊天体验（拟人是核心目标）

- **碎片式多气泡回复**：一句话拆成几条发，像真人打字（气泡上限可配）
- **智能攒批**：你连发好几条，她攒一起看完再回；冷场后第一句话会多等几秒（静息档）
- **抢答**：小概率抢在你话说完前接话（20% 触发，带人设和上下文）
- **思考中插话重想**：她生成到一半你又发消息，整轮压住重想，不会自问自答
- **主动开口**：空闲久了她会在 8~23 点之间主动找你，有间隔和日上限

### 表情包与语音

- **情绪发图**：根据聊天情绪从图库抽表情（15 个情绪桶，SQLite 索引）
- **自主图库**：聊天里的图她自动收进私藏图库，视觉模型看图打标签归位；她自己会用工具翻家底、改标签、删图（回收站可恢复）
- **语音回复**：本地 GPT-SoVITS 推理，音色自己训练（仓库不含任何音色模型与录音，附训练指南）

### 工具与 Agent 能力

- **人人都有**：查新闻搜资料、自然语言闹钟（到点用她的口气催）、沙盒文件助理（读/写/发自己目录里的文件、压缩解压）
- **仅主人**：本地文件与 Word 读写、联网下载（SSRF 防护）、shell 命令（高危命令硬黑名单，删除类全禁）、把重活外包给本机 Kimi Code CLI（先请示后派活，控制台有总闸）
- **安全双闸**：硬关键词拦截 + 轻量模型分类闸；高危工具对普通用户永不开放，安全闸不可按用户关闭

### 多用户与运营

- **积分体系**：发消息扣分、每日赠送、控制台发放，余额不足自动婉拒
- **按用户开关**：回复/语音/主动/表情包/收图/闹钟/文件助理等 10 项功能可按用户单独开关
- **网页控制台**：状态总览、日志、聊天记录（图片直接看、语音直接听）、开关管理、积分发放、管理员代发消息（不留记忆）、机器人进程一键启停、token 成本与缓存命中率监控

## 技术实现

```
QQ 开放平台（官方 Bot API，WebSocket 长连接）
        │
        ▼
AstrBot 4.x（消息框架 / 插件容器 / 识图管线）
        │
        ▼
astrbot_plugin_dsh_soul（本仓库核心，Python 约 3500 行）
 ├─ 模型层：DeepSeek 对话 + 视觉识图 + 轻量模型分类闸/抢答
 ├─ 记忆层：JSON 持久化（历史/长期记忆/摘要/念头）
 ├─ 图库层：SQLite 索引 + 情绪桶抽取 + vision 自动打标
 ├─ 语音层：GPT-SoVITS 本地推理（127.0.0.1:18765）
 └─ 工具层：文件/下载/shell/闹钟/外包 CLI（uid 硬闸）
        │
        ▼
dsh-console（Node.js 零依赖原生 http，127.0.0.1:7850）
```

- **为什么走官方接口**：不用第三方协议端，账号风险低，个人开发者免费注册即可接入
- **成本控制**：框架层上下文封顶 8 轮 + 截断策略，日常聊天单轮输入从 ~10 万 token 压到 ~1.6 万；控制台可看缓存命中率
- **隐私设计**：全部数据本地存储（`dsh_data/`），不上传任何第三方；管理员代发消息不写入记忆

## 运行前提

- 一台常开 Windows 机器（语音功能需 NVIDIA 显卡，无显卡可关语音）
- Python 3.10+、Node.js 18+（控制台用）、ffmpeg（语音功能用，加入 PATH 即可）
- QQ 开放平台机器人账号（个人可免费注册）
- DeepSeek API key（按量付费，日常聊天一天几块钱量级）
- AstrBot 4.x（插件放进 `data/plugins/` 即可）

详细部署见 `docs/项目交接文档.md`，功能清单见 `docs/移植验收清单.md`。
