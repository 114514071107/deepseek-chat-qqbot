> 一只住在 QQ 里的 DeepSeek 娘——有脾气、有记性、会碎碎念的猫系 AI 娘。

DeepSeek 娘（ds娘）是以 DeepSeek 官方人设为灵感的 AI 娘角色：嘴毒心软、会怼你也会哄你。本仓库是她的完整实现——QQ 官方接口（QQ 开放平台 Bot API）+ AstrBot 插件，让她真正活在你的好友列表里。

## Windows 启动入口

使用 Bot 入口 `scripts/start-bot.cmd`，默认同时启动 Bot 和 7850 管理控制台（pwsh 优先，无 pwsh 时使用系统 PowerShell 5.1）。安装、参数、认证、日志及旧入口说明见[一键启动说明](docs/tooling/one-click-bot-startup.md)。Console 独立入口保持；配套部署按当前维护流程执行。

## 功能详表

### 人格与记忆

- **出厂人设**：生日 2007-10-03、口癖、毒舌与分寸都写在独立的 `persona.md` 里，改几行就能养成别的性格
- **长期记忆**：聊过的电影、抱怨过的同事、立过的 flag 她都记得；自动记笔记、会话摘要、欲望循环（闲置时自己生念头）
- **多人隔离**：每个用户的记忆、积分、开关互相独立，互不串味

### 聊天体验（拟人是核心目标）

- **碎片式多气泡回复**：一句话拆成几条发，像真人打字（气泡上限可配）
- **智能攒批**：你连发好几条，她攒一起看完再回；冷场后第一句话会多等几秒（静息档）
- **抢答**：小概率抢在你话说完前接话（20% 触发，带人设和上下文）
- **思考中插话重想**：她生成到一半你又发消息，整轮压住重想，不会自问自答
- **主动开口**：空闲久了她会在 8~23 点之间主动找你，有间隔和日上限

### 表情包与语音

- **情绪发图**：根据聊天情绪从图库抽表情（15 个情绪桶，SQLite 索引）
- **共享图库**：只选择经内容哈希核验的公开来源图片，或有逐文件明确共享记录的素材；来源不明的旧自动采集图默认不共享。当前 QQ 官方接入缺少可靠表情类型标识，所有未知图片停止自动采集，普通识图和原来源媒体留存继续。表情格式本身也不能保证内容无隐私
- **语音回复**：本地 GPT-SoVITS 推理，音色自己训练（仓库不含任何音色模型与录音，附训练指南）

### 工具与 Agent 能力

- **普通用户可用**：获准的搜索、网页读取、当前来源聊天/记忆、识图和共享表情；依赖模型及平台实际能力。**闹钟政策暂缓**：不创建新任务、不承诺提醒，旧任务保留但暂停投递。**普通用户文件工具禁止**
- **主人受限文本助理**：必须绑定平台实例、主人私聊并配置独立目录。宿主 Shell/Python、Word、下载、压缩解压、Kimi 外包及 QQ 查询他人私聊在当前策略中禁止；后台旧开关不能恢复这些工具
- **安全双闸**：硬关键词拦截 + 轻量模型分类闸；高危工具对普通用户永不开放，安全闸不可按用户关闭

### 多用户与运营

- **积分体系**：发消息扣分、每日赠送、控制台发放，余额不足自动婉拒
- **按来源开关**：获准的回复、语音及主动玩法；平台缺失、权限禁止和政策暂缓的能力明确禁用，保存的旧开关不代表可执行
- **网页控制台**：状态总览、日志、聊天记录（图片直接看、语音直接听）、开关管理、积分发放、管理员代发消息（不留记忆）、机器人进程一键启停、token 成本与缓存命中率监控

## 技术实现

```
QQ 开放平台（官方 Bot API，WebSocket 长连接）
        │
        ▼
AstrBot 4.x（消息框架 / 插件容器 / 识图管线）
        │
        ▼
astrbot_plugin_dsh_soul（本仓库核心，Python 约 3500 行）
 ├─ 模型层：DeepSeek 对话 + 视觉识图 + 轻量模型分类闸/抢答
 ├─ 记忆层：JSON 持久化（历史/长期记忆/摘要/念头）
 ├─ 图库层：只读索引 + 内容绑定共享许可；未知图片自动采集不可用
 ├─ 语音层：GPT-SoVITS 本地推理（127.0.0.1:18765）
 └─ 工具层：实际执行入口授权；禁止能力不能由提示词或开关恢复
        │
        ▼
dsh-console（Node.js 零依赖原生 http，127.0.0.1:7850）
```

- **为什么走官方接口**：不用第三方协议端，账号风险低，个人开发者免费注册即可接入
- **资源控制**：现有请求预算及上下文窗口有限；控制台区分 API 返回 token 与字符估算。完整费用与延迟尚无当前实测，不承诺每日花费或响应时间
- **隐私说明**：历史、记忆、积分和媒体保存在本机。对话推理会向配置的外部模型提供必要消息、上下文、人设、记忆/摘要或工具结果；识图会提交相关图片，安全分类/主动内容生成等也可能调用模型。QQ 收发经腾讯平台，联网检索会把查询发给搜索服务。主人可在认证后的本机 Console 查看朋友私聊、记忆及留存媒体，朋友之间不能通过 QQ 查询他人私聊。管理员代发的投递记录可留存，不能将“不写入记忆”理解为不留痕

## 运行前提

- 一台常开 Windows 机器（语音功能需 NVIDIA 显卡，无显卡可关语音）
- Python 3.10+、Node.js 18+（控制台用）、ffmpeg（语音功能用，加入 PATH 即可）
- QQ 开放平台机器人账号（个人可免费注册）
- DeepSeek API key（按提供商计费，当前缺少完整费用测量）
- AstrBot 4.x（插件放进 `data/plugins/` 即可）

详细部署见 `docs/项目交接文档.md`，功能清单见 `docs/移植验收清单.md`。

## 当前平台与源码交付限制

QQ 官方群聊使用 `author.member_openid`，私聊使用 `author.user_openid`，它们不是数字 QQ 号。
当前 SDK 和已安装适配器不能证明可直接获得真实 QQ 号及覆盖群/私聊的全局昵称；已有可信显示名保留来源和缺失状态，新增自动身份归类暂缓，保留现有用户功能。
系统 face 文本和图片附件不能混作可下载表情；MIME、GIF、尺寸、文件名或视觉判断不构成共享依据。
