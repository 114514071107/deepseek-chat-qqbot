## F02 的修改和行为

- `console/server.js` 导出 `createConsoleServer` 供隔离测试，正常命令启动仍为 Node 原生 HTTP。所有路由（页面、媒体、历史、管理 API、未知路由）先过同一个认证入口。
- 认证为 HTTP Basic：用户名固定 `dsh`，密码为外部环境变量 `DSH_CONSOLE_TOKEN`。没有令牌或格式不足时拒绝启动；比较使用固定长度摘要和 timingSafeEqual。令牌不放 URL、HTML、本地存储、源码或测试固定值中。
- 只允许监听 `127.0.0.1`，Host 必须为本端口的 `127.0.0.1` 或 `localhost`。Origin 存在时必须同源；跨站 Fetch Metadata 被拒。写请求额外要求精确同源 Origin、JSON Content-Type 和 `X-DSH-Request: 1`。这项自定义头是浏览器不能通过普通跨站表单附带的条件；它不能代替认证。
- `console/public/index.html` 的既有请求封装自动附加该头。浏览器首次打开页面会显示原生认证窗口；媒体和音频 Range 请求继续使用浏览器缓存的凭据。前后端版本一起升为 `20261022-security-1`。
- 请求体最多 64KiB，拒绝无效 JSON 和非对象；设置请求/请求头时间上限和 no-store、no-referrer、nosniff、DENY 响应头。
- `network_safety.py` 统一公网抓取：仅无内嵌凭据的 HTTP(S)，每一跳 DNS 的全部结果都必须为公网地址，禁止混合内网地址；直接连接该次核准的数字 IP，并检查 peer；TLS 仍校验证书和原始域名，Host 也保留原域名。忽略代理环境变量，不进行连接时的第二次 DNS 查询。
- 整次抓取共用总截止时间，包含 DNS、连接、TLS、响应头、各跳和正文；超时 watchdog 关闭连接，避免靠逐次 socket 超时被慢速滴流拖住。DNS 使用最多四个短生命周期守护线程，卡住后拒绝新解析，避免不断累积解析线程。
- 网页最多 2MiB、15 秒、5 次重定向。超限正文、异常长度、截断正文及非 identity 压缩响应均拒绝。搜索引擎抓取、QQ 附件远程留存和表情采集也复用该连接边界，保持各自原有的数量/体积上限，不改固定 QQ API 与本机 TTS 请求。

## 工作单 2 的接口

- `Caller(platform, instance, sender, private, group)`、`caller(event)` 是本轮可信身份入口；不从 UMO 最后路由或模型参数推导身份。
- `authorize(event, name, master, user_perm, owner_instance=..., consume=...)` 是策略；`_authorize_tool` 叠加实时总开关与 reply。新增工具必须进入显式清单、加入口装饰器、纳入矩阵和分发检查。

- 本单不建立目标快照、后台任务管理、分层删除和发送成功协议；后续按 TASKS 中 F01/F04/F05/F08/F06/F07 的接口继续。
