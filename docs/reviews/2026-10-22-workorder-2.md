## F01：会话与来源

键使用 JSON 数组的 SHA256，保留完整值在受保护的本机来源表；哈希只是稳定键，不是身份认证。

| 用途 | 来源字段与边界 |
| --- | --- |
| 个人记忆/个人资源键 `p2_…` | 平台类型、平台实例、机器人 self_id、发送者 |
| 私聊对话键 | 与该人的 `p2_…` 相同 |
| 群中个人对话键 `c2_…` | 上述字段再加当前群；同群不同成员分别建上下文 |
| 当前群历史键 `g2_…` | 平台类型、平台实例、机器人、当前群；只记录实际经过插件保存的消息 |
| 框架会话 | `实例:消息类型:个人对话键`，模型锁、会话历史、默认工作区同步分开 |
| 真实发送目标 | 独立保存原始目标地址，不用内部会话哈希发送 |

在消息 gate（priority 100）绑定作用域，早于框架模型锁和附件工作区选择。inject 清除框架旧 contexts，以插件 v2 来源明确的历史作为输入，避免两份历史叠加。群请求不读私聊笔记、画像、摘要或私聊学到的资料；人设与授权共享表情目录仍是公共素材。

新记录保留 sender、group、platform、instance、bot、message_id、private 和时间。群 recall 只检索当前 `g2_…`，不按昵称、最后路由或模型参数扩展范围；不额外 @ 成员。没有来源证据的旧记录不自动进入新模型输入，也不自动 bootstrap 成新归档。

历史、摘要、念头、缓冲、打断、生成标志、待发内容、收件工作区按对话键处理。搜索冷却、采集和主动消息资源计数按个人键共享，不能通过换群重置现有限制。采集按实际额度文件排他登记任务，避免同人在不同群同时采集导致计数覆盖；已有 raw uid 当天上限继续生效。私聊主动消息需明确开启，群默认开启；控制台显示相同的有效默认值。

## F05：任务、请求和开关

所有原 create_task 入口纳入 Runtime，包括永久循环、滴灌、延时话语、抢答、语音、下载后处理、采集、摘要、记忆和被禁用工具的外包实现。AstrBot 注册装饰器保存的实际回调也受 `@managed` 保护；没有只替换类方法而漏掉原注册引用。

每个实例、对话、请求有可撤销身份。框架事件任务在模型钩子后继续登记，因此关闭 enabled/reply 可以取消框架内部尚在延时的首气泡；不仅检查插件 `_send`。关闭旧 raw uid 的继承权限也会撤销受影响的新会话，具体新会话的显式配置按规则保留。新请求/删除使旧回调失效，旧 finally 不能清理新请求标记。下载线程只取得字节，返回后再核对身份和开关；终止后不能继续提交或发送。

`terminate()` 取消并等待受管及借用事件任务，收集异常；重复加载不叠加循环。局部提醒、启动问候和管理代发使用独立作用域任务，局部撤销不会杀死全局念头循环或管理通道。外包取消会 kill 并 wait 子进程，测试仅使用替身。主人 QQ 总开关与控制台使用同一状态修改入口；可信的总开关命令有单独控制身份，关闭后仍可重新开启。

取消不能撤回此前已提交给外部平台的请求；本单验证撤销后的后续发送与保存不再发生，已在途请求的结果分类交给 F06。

闹钟循环只纳入生命周期。旧 `umo_all.json` 不再被普通新聊天改写，保留给暂缓的闹钟兼容路径；没有迁移闹钟目标、决定补发、休眠或开关政策。第三单不能把该旧路由当成新的可信 Target。

## F08：权威修改、删除与兼容

控制台不再直接写聊天状态文件。认证通过后，它提交带随机编号、运行实例和截止时间的本机文件命令；插件应用内存与磁盘后确认。离线、过期、实例更换、保存失败都不会返回已生效。超时标记结果未知，可用 `/api/admin/result?id=…` 查询，页面会短暂继续查询。已领取命令不自动重放，避免确认失败后重复加积分或发送。

JSON/Markdown 读取只把 FileNotFound 当作缺失；损坏、权限等错误明确失败。写入使用唯一临时文件、flush/fsync 和原子替换，错误向调用者传播。插件是单机运行状态的写入者；原子替换本身不被当作跨进程事务。管理删除按作用域暂停新请求、撤销并等待旧工作，随后逐层执行；其他对话可以继续。

| 可选层 | 处理范围与保留边界 |
| --- | --- |
| 滚动历史 | 所选来源的插件历史及可准确定位的新框架 Conversation；旧框架来源无法定位时返回部分完成 |
| 归档 | 所选来源的 JSONL 和其在群共享历史中的记录；同群其他来源保留 |
| 摘要 | 本会话摘要、临时念头 |
| 长期记忆 | 本来源笔记、学习资料、私有 Markdown 画像；旧全局学梗资料不能归到某个人，保留并报告 |
| 媒体 | 已登记/关联的收件、语音和附件；被其他来源引用的文件保留并报告部分完成；共享图库保留 |
| 备份 | 数据目录根的 `.bak*` 文件和 `dsh_data/backups` 内明确选中的整份文件；须确认其他用户影响；外部、系统及部署备份不在此删除入口范围 |

默认不选任何层。全选会勾选六层与已列备份，整份备份影响仍需明确确认。没有暗中新增删除前备份。各层分别返回 done / partial / failed 与保留内容，不能把选中的滚动历史清理称作所有记录已经消失。不是六层跨文件的整体事务，失败时可能有部分层已完成，必须按返回结果核对。

旧 `history_all.json`、旧归档、raw uid 笔记/摘要等保留为控制台旧档。新来源表和历史使用 `*_v2.json`、`history_archive_v2.jsonl`；不从最后路由推断旧聊天归属。已有 raw uid 的显式拒绝作为保守限制继续生效，受保护控制台对具体新来源的显式配置可覆盖；旧“允许主动消息”不被猜成私聊主动授权。已有积分、主动额度及当天采集额度按原标识保守续用，避免新键白送额度；新用户用个人键。这些是限制兼容，不是给旧聊天推断平台/群归属。

未实现自动生产迁移。回归在临时数据/副本中验证了保留旧层、分层删除、全选及不可准确定位的旧框架历史返回部分结果。生产旧档如果将来要归属，需另有可信来源清单并先备份演练；不能把本单通过当作迁移已经成功。
