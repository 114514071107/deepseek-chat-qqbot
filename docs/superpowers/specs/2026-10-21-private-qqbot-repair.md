# 自用 QQ 机器人修复范围

## 用户目标

把已经部署的项目修好，供自己和朋友使用；继续以 QQ 机器人形式运行，技术栈继续使用 AstrBot 插件。

## 约束

- 保留当前 AstrBot 4.29.1、Python 3.12、uv/venv、QQ 官方机器人接入和配套 Node.js 控制台。
- 保留现有人设、表情、记忆、主动消息、闹钟等玩法；先修已有缺陷，不增加新的 Agent 平台或迁移框架。
- 以本地首轮审查报告的 R01–R13 为本次修复范围，每项有回归验证。
- 不用真实聊天记录、密钥或真实 QQ 发送做自动化测试；语音服务未部署也应能正常文字聊天。
- 源码在 Git 开发目录中修改；运行环境保留在 `D:\dsbot`，已有配置和用户数据不得被模板覆盖。
- 每个可独立验证的修复分批提交；备份后才更新运行副本，保留可回退的代码与数据。
- 继续保留 AGPL-3.0、上游署名和修改说明；个人密钥、用户身份与聊天数据不进入 Git。

## 验收

对 R01–R13 的触发场景分别验证修复后行为，完成 Python/Node 自动化检查和独立代码复核。更新本机后，检查两个管理页面、插件加载与 QQ 连接状态，再由用户实际验证私聊、群聊及常用指令。
